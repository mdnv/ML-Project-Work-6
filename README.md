# Предобработка и классификация текста

Учебный проект: определение группы позиции футболиста по текстовому полю `playstyles` из `players.csv`. Классы: вратарь, защитник, полузащитник и нападающий.

## Что сделано

- Исключены строки без текста. Использовано 8 051 наблюдение.
- Реализованы нижний регистр, удаление пунктуации и цифр, токенизация и удаление английских стоп-слов. Сохранены отрицания и слова `first/out`, значимые для названий стилей.
- Собран пайплайн: очистка → TF-IDF → логистическая регрессия с балансировкой весов классов.
- TF-IDF использует униграммы и биграммы, `min_df=2`, `max_df=0.95`, `max_features=3000`.
- Данные разделены на train/test в пропорции 80/20. Векторизатор обучен только на train.
- Рассчитаны метрики, построена матрица ошибок и разобраны пять неверных предсказаний с гипотезами о причинах.

## Результаты проверенного запуска

| Показатель | Значение |
|---|---:|
| Train / test | 6 440 / 1 611 |
| Размерность TF-IDF | 354 |
| Accuracy | 0,7349 |
| Macro-F1 | 0,7661 |

Основная метрика — macro-F1: она учитывает каждый класс с одинаковым весом при дисбалансе данных.

## Файлы и запуск

- `data/players.csv` — исходные данные.
- `notebooks/text_preprocessing.ipynb` — код, результаты и выводы.

Установить библиотеки в окружение проекта:

```bash
python -m pip install pandas matplotlib ipykernel "scikit-learn==1.8.0"
```

Открыть ноутбук в VS Code, выбрать ядро окружения проекта и нажать **Run All**.

Модель принимает список игровых стилей, очищает его, преобразует в TF-IDF-признаки и предсказывает группу позиции. Качество относится только к игрокам с заполненным `playstyles`. Данные содержат списки терминов, поэтому результат нельзя автоматически переносить на отзывы и другие связные тексты.
